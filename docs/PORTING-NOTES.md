# FLIP Windows -> macOS Porting Notes

> **Scope note:** this mapping was written against the earlier Windows
> implementation. The current upstream `v0.6.1` adds capabilities that are
> not all represented here. See
> [CROSS-PLATFORM-COLLABORATION.md](CROSS-PLATFORM-COLLABORATION.md) for the
> dated compatibility audit, explicit gaps, licensing boundary, and proposed
> collaboration path.

This document maps every module in the original Windows (`C#` / `.NET` / WinForms / GDI+) implementation (`FLIP-windows/src/Flip/*.cs`) to its counterpart in `FLIP-macOS-port` (`Tauri v2` + `Rust` + `Swift` Cocoa/Apple frameworks + `TypeScript/Vite`), and records intentional platform deltas and enhancements.

---

## 2. Core Parity Rules Preserved

1. **Non-destructive conversions & atomic commits**: Conversions always render inside temporary staging directories and commit atomically into the target directory using Finder collision suffixes (`photo 2.png`). Originals are never overwritten or deleted.
2. **Drag-and-Trigger state machine (`core/input_gate.rs`)**: Trigger held before drag starts, OR trigger pressed after Finder drag starts, opens the wheel exactly once per drag session without re-opening until mouse-up. Release outside `210 px` dismisses; release inside the `68 px` center hub keeps the wheel open in Idle mode.
3. **3 deg Angular Hysteresis & Pagination (`src/wheelGeometry.ts`)**: Moving near sector borders never causes flicker; >8 items automatically paginate into pages of <= 8 sectors using `More ▸` / `Back ◂` with 300 ms drag-dwell page flipping.
4. **Defensive Container & Document Limits (`core/policy.rs`, `engines/document.rs`, `engines/image.rs`)**: Enforces 4096 container entries / 256 MiB decompressed limits on ZIP/OOXML/ODT/EPUB archives, strips DOCTYPE/ENTITY (XXE) declarations, ignores unsafe local `file://`/external links in HTML rendering, rejects symlinks / Finder aliases / un-downloaded `.icloud` placeholders, and respects 40 MP / 200 MP / 200-page ceilings.
5. **Inline Rename Separation**: Inline rename in Finder is invoked **only** for newly created files/folders (`create_new`), **never** for converted outputs.

## 3. Intentional macOS Deltas & Enhancements

- **Pure-Rust Built-in EPUB 3, FB2 & RST Engines**: Unlike Windows (which required Pandoc for EPUB/FB2/RST), `src-tauri/src/engines/document.rs` implements native EPUB 3 reading/writing, native FictionBook 2.0 (`FB2`) reading/writing, and native reStructuredText (`RST`) reading/writing. Pandoc is purely optional (and can be bypassed via `FLIP_DISABLE_PANDOC=1`, alongside `FLIP_DISABLE_FFMPEG=1` for audio/video).
- **Native Apple Frameworks**: `ImageIO` (HEIC/AVIF/EXIF/GPS strip, offline-sanitized `SVG`), `PDFKit` + `Vision` OCR & `REMOVE_BG`, `NSAttributedString` / CoreText, `AVFoundation` + CoreAudio/`afconvert` (`CAF`/`FLAC`), `QLThumbnailGenerator`, `NSHapticFeedbackManager`, and `AppleScript` iWork integration replace Windows GDI+/COM dependencies.
- **Trigger Defaults**: Default drag trigger is `DownArrow` (configurable to Mouse Buttons 2/3/4/5 or keys); default Idle hotkey is `Option+Shift+Space` (avoiding Windows `Ctrl+Alt+F`).
- **Accessibility & Customization Upgrades**: Interactive Preferred Format Order editor (move left/right, drag-and-drop, reset to default) in Settings -> Formats & Quality, `prefers-reduced-motion` / `prefers-reduced-transparency` CSS compliance, and full VoiceOver support with `.sr-only` `aria-live="polite"` announcements across open, sector switch, pagination, progress milestones, and completion/error states.
- **Additional Surfaces**: Batch / Multi-Format Queue window (`#batch`), First-Run Onboarding wizard (`#onboarding`), Finder Quick Actions (`~/Library/Services/*.workflow`), `flip://` deep links, `flip preview --out` SVG generator, and full CLI subcommands (`flip convert`, `flip new --json`).
- **Distribution Model**: Open-source MIT license packaged as signed ad-hoc arm64 `FLIP.app` and `FLIP-0.1.0-macOS-arm64.dmg` (no paid Apple Developer ID notarization assumed), with `scripts/install-local.sh` (port of `Install.ps1`) and Homebrew Cask `packaging/homebrew/flip.rb`.
